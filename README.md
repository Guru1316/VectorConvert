# VectorConvert


**VectorConvert** is a sleek, user-friendly web application designed to quickly convert data between JSON and CSV formats. Built with React and powered by Papaparse, VectorConvert enables developers, data analysts, and enthusiasts to seamlessly transform data with ease — all through an intuitive interface featuring dark mode support, file upload, copy, and download capabilities.

## Features

- **JSON to CSV Conversion**  
  Paste or upload JSON data and convert it instantly to CSV format.

- **CSV to JSON Conversion**  
  Paste or upload CSV data and convert it into formatted JSON.

- **File Upload Support**  
  Upload `.json` or `.csv` files directly to convert without copy-pasting.

- **Copy & Download Output**  
  Easily copy the converted data to clipboard or download it as a file.

- **Dark Mode Toggle**  
  Switch between light and dark themes for comfortable usage anytime.

- **Input Validation & Error Alerts**  
  Alerts users when invalid JSON or CSV data is provided.

---

## Why VectorConvert?

Data interchange between JSON and CSV is a common task for developers and analysts. VectorConvert simplifies this process in a clean, responsive web app — no need for complex software or command line tools. Perfect for quick transformations, testing APIs, and data handling workflows.

---

## Tech Stack

- **React + TypeScript** — Frontend framework with strong typing.
- **Papaparse** — Powerful CSV parser and stringifier.
- **Bootstrap 5** — Responsive and sleek UI components.
- **Vite** — Lightning-fast build tool for modern frontend development.
- **GitHub Pages** — Free hosting for the live demo.
